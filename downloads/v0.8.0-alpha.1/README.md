# Alien Client Unified 0.8.0-alpha.1 — Emote Studio

Minecraft Java **1.8.9 / Forge 11.15.1.2318 / Java 8**. Floss, Orange Justice e Take the L, roda na tecla B, prévia com o jogador real, oito posições, velocidade e repetição. Integra perfis e preserva HUD/Full, trilhas, cosméticos e os estúdios anteriores.

Em um mundo, segure **B**, aponte e solte. Andar/atacar/usar itens/receber dano interrompe a dança. Abra **Cosmetic Studio → Emotes** para personalizar. As animações são adaptações originais para o modelo rígido do Minecraft: não há música nem sincronização com outros jogadores.

Instale um único JAR Alien na pasta `mods`. Alpha em branch separada, sem merge na main. Autenticação Microsoft e gameplay em Windows físico/GPU física não foram validados.
