# Unified 0.13.0-alpha.1 — Fantasma Neon

Minecraft Java 1.8.9 / Forge 11.15.1.2318 / Java 8. Efeito de eliminação 3D com animação suave, Ghost Studio, cores e perfis. Now Playing e os recursos anteriores continuam incluídos.

[Baixar JAR](AlienClient-Unified-1.8.9.jar) · [ZIP de instalação](AlienClient-Unified-Primeiro-Teste.zip) · [Hashes](SHA256SUMS.txt) · [Recibo](RESULTADO-DOS-TESTES.txt).

Abra **Effects Studio → Ghost Elimination**. O efeito começa desligado. A prévia usa o renderizador real, mas não conta como kill. Em multiplayer, o disparo depende das mensagens de morte vanilla reconhecidas; feeds personalizados de texto não são interpretados.
